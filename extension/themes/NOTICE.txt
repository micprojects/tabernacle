Mozilla Firefox theme material

mozilla.js contains the unmodified manifest data for Sun, Spark, Flame, Flare,
Lavender, Dusk, Lagoon, Pine, Tide, Ash and Smoke, published by Mozilla, version
1.1. Each entry records the official listing, download URL, archive SHA-256 and
licence. Flame's official listing is nova_flame (not nova-flame).

background gradients to its viewport; the stored manifests are unchanged.

Firefox Default keeps the Nova colour roles without native platform materials.
Its sidebar uses quiet neutral surfaces, with subtle highlights drawn from the
appearance's accent colour. Forced colours use system colours. Third-party theme
matching uses exposed colour data only: Firefox's theme.getCurrent returns the
base definition and cannot reliably expose separate dark_theme definitions. Missing roles use
Firefox's Nova defaults; no third-party theme images or external assets load.

Variant selection uses the sidebar's prefers-color-scheme media query, which
follows browser chrome independently of website colour overrides.
On macOS, missing popup backgrounds use the native chrome values (white /
#1e1e1e), verified by the Firefox integration test: extension documents resolve
Field to a different, generic dark colour. Other platforms retain system Field.
